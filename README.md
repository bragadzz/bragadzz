### Projetos

**Season** — app de treino para iOS e o backend dele.
`season-app` em Swift e SwiftUI, iOS 17+: planilha gerada por regras, execução do treino e um
feed social. `season-api` é um monolito modular em Node 24 com Fastify, Drizzle e PostgreSQL 18,
separado por módulo (contas, treino, comunidade, stories, atividade, mídia, notificações,
privacidade, assinaturas, painel). Os dois são meus.

**YuvexPay** — gateway de pagamento com Pix: API, painel, checkout e apps nativos.
Sou admin da organização. O app iOS (Swift/SwiftUI) e o Android (Kotlin/Jetpack Compose) são
meus, incluindo o push por FCM. Backend e painel são de outras pessoas do time.

**Agendaqui** — atendente por WhatsApp para clínica: agenda, remarca, cancela, confirma e passa
para a recepção quando precisa de gente. Fastify, MongoDB com Prisma, BullMQ e Redis, com o
provedor de IA escolhido por variável de ambiente.

**NeverMiss** — painel web e bots para comunidades do Discord. É a minha base de código mais
antiga ainda em atividade, com histórico desde dezembro de 2024; o bot atual é uma reescrita em
TypeScript com discord.js.
